# 🛡️ RazorShield

### AI-Powered Transaction Fraud Detection & Risk Management

RazorShield is a machine learning-based fraud detection application designed to assess financial transactions and classify them into different risk levels.

The application combines a trained machine learning model with a Streamlit dashboard to provide transaction-level fraud probability, risk scores, decisions, risk distribution, and high-risk transaction analysis.

---

## 🚀 Features

- 🔍 Transaction fraud prediction
- 💰 Transaction amount analysis
- 📊 Risk dashboard
- 🔴 High-risk transaction identification
- 🟡 Medium-risk transaction identification
- 🟢 Low-risk transaction identification
- 📈 Risk distribution visualization
- 🤖 Machine learning-based prediction
- 🧠 Feature preprocessing pipeline
- 📋 High-risk transaction table
- 📌 Fraud probability and risk score
- ⚡ Manual transaction assessment
- 📊 Model performance metrics

---
